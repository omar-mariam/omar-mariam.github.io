# دعوة فرح عمر ومريم

الاثنين 14-12-2026، الساعة 8 مساءً — قاعة سيرا (رجال) وقاعة أوليڤيا (نساء)، طلخا، المنصورة.

اللينك: https://omar-mariam.github.io

## الملفات
- `index.html` — الدعوة كلها. البيانات (الأسامي، الميعاد، القاعات، لينكات الخريطة) في `CONFIG` تحت في الملف.
- `door.webp` — صورة الباب المملوكي (941×1672). الضلفتين متقاسين عليها بالبكسل؛ لو الصورة اتغيرت لازم القياسات تتغير.
- `verse.mp3` — تلاوة الآية (الروم 21) بصوت ماهر المعيقلي، من everyayah.com. بتتقري بدل الموسيقى.
- `preview.jpg` — صورة معاينة اللينك في واتساب (1080×1080).
